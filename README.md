# TTS Clips

Локальный редактор коротких текстов. Создайте клип, введите название и вставьте текст. Сегменты появляются после автосохранения. Нажмите на сегмент, чтобы выделить его в тексте. После закрытия браузера клипы остаются в SQLite.

## Запуск на Windows

Нужны Python 3.11 и Node.js 22. Выполните команды в PowerShell из корня проекта.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
npm run build
.\.venv\Scripts\python.exe -m uvicorn clips.main:create_app --factory --host 127.0.0.1 --port 8765
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765). При последующих запусках достаточно команды Uvicorn. После правки интерфейса повторите сборку. Для остановки сервера нажмите Ctrl+C.

Путь к базе по умолчанию — `data/clips.sqlite3`. Для изолированной рабочей области задайте `TTS_CLIPS_DB` перед запуском. Перед закрытием дождитесь статуса «Сохранено». При конфликте вкладок можно сравнить редакции и открыть сохранённую версию либо явно сохранить свой черновик поверх неё.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
npm run build
```

Тесты поднимают отдельные базы и проверяют разбиение текста, точное покрытие, ID повторяющихся реплик, хранение редакций и конфликт одновременных записей. Этот выпуск охватывает редактор, хранение и сегментацию. Архитектура следующих этапов описана в [C0A](docs/C0A_Source_Audit_and_Architecture_Proposal.md).
