# TTS Clips

TTS Clips помогает команде озвучивать готовые русские переводы. Монтажёр готовит текст и голос, выбирает дубли, сверяет речь с расшифровкой Whisper и скачивает WAV или MP3. Тексты, голоса, аудио и история выпусков сохраняются на сервере.

Для корпоративной установки на двух серверах используйте [Docker-поставку C1.11](docs/C1.11_Docker_Deployment.md). Она запускает frontend с NGINX на одном сервере и backend с локальной NVIDIA GPU на другом.

## RHEL 9 · 0.1.0 RC1

На одном сервере работают FastAPI с готовым React-интерфейсом, VoxCPM2 на NVIDIA GPU, Whisper на CPU, SQLite и хранилище аудио. Монтажёры открывают корпоративный HTTPS-адрес. Администратор устанавливает RPM и запускает `sudo tts-clips-setup`, чтобы установить Python-зависимости, загрузить модели и включить службу.
